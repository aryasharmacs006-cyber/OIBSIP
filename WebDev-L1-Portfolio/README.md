# Personal Portfolio

**Oasis Infobyte SIP** · Web Development & Designing · Level 1 · Task 2

A single-page personal portfolio for Arya Sharma in a "cherry red dark academia" style: warm dark paper tones, cherry red accents and gold details, set in Cormorant Garamond and EB Garamond. It has a hero with a framed portrait, an About section with experience and honours, an indexed Skills list, five Projects, a downloadable resume, and a Contact section. A star cursor with a glitter trail runs on desktop only.

## Checklist

- [x] Hero: name, role title and portrait
- [x] About Me: 2 to 3 sentences
- [x] Skills: index list with a level word for each skill
- [x] Projects: cards with title, short description, tools, and Live and GitHub links
- [x] Contact: name, email, LinkedIn and GitHub inline SVG icons
- [x] Smooth-scroll navigation between sections
- [x] One colour scheme and one font pairing
- [x] Responsive: no horizontal scroll at 390px, 16px side padding on mobile
- [x] `box-sizing: border-box` everywhere
- [x] Clear type scale
- [x] HTML5, CSS3 and small touches of JavaScript; readable with JavaScript off
